Build a **responsive, full-stack web app** called **“Adifit Style Coach”** with a **cool, Adidas-inspired, classy design**.

**Goal:**  
Help users discover Adidas-style sport outfits, try them virtually on their photo (AI), and generate a personalized training plan with dual-view scheduling and sharing options.

---

### 🎨 Branding & Design
- **Logo + Navbar**: `logo.png` with app name “Adifit Style Coach”  
- **Adidas-classy theme**: black, white, accent blue, subtle gradients, modern fonts, soft shadows, rounded corners  
- **TailwindCSS**: responsive, mobile-first, sleek styling  
- Include **hover animations** on buttons, cards, and outfit items  
- Personalized greeting:  
  > “👋 Hello, [Name]! Check your suggested looks and training plan.”

---

### 🧍‍♀️ User Input Form
Collect:
- Name, Age, Gender, Fitness Goal, Location  
- Preferred Weekdays (Mon–Sun)  
- Preferred Start Time (HH:MM)  
- Session Duration (30/45/60)  
- Upload Photo (for AI try-on)  
- Validate input and store in React state

---

### 👟 Outfit Recommendations
- Display **3 mock Adidas options each** for Shoes, Clothes, Accessories  
- Show **image, description, price**  
- Include **“Add to Look” / “Try On” button**  

---

### 💡 Suggested Looks
- Generate **3 full outfit combinations**: Look 1, Look 2, Look 3  
- Each look = shoes + apparel + accessories  
- Display **images, descriptions, prices**  
- **Single Try-On button per look**:  
  - Sends user photo + look images to **Google Gemini Virtual Try-On API** or **OpenAI Sora 2**  
  - Generates **composite AI try-on image per look**  
  - Display **all 3 AI try-on images side-by-side** for comparison

---

### 📅 Training Plan Generator
- Generate **weekly plan** based on weekdays, start time, duration  
- Display in **two views**:
  1. **Quick/Compact View**: simplified, color-coded with key info (day, time, duration)  
  2. **Detailed View**: full table with workout type, duration, notes, and optional links
- Integrate **FullCalendar** for interactive calendar:
  - Drag & drop to reschedule  
  - “Mark Done” buttons  
  - Toggle between Quick/Compact and Detailed views

---

### 📤 Social Share
- **“Share My Style”** button:
  - Capture outfit preview + training plan (canvas or card)  
  - Generate **shareable image**  
  - Share via **Web Share API** or download

---

### 🧠 Virtual Try-On
- Frontend: Axios to Flask backend  
- Backend: Flask `/tryon` endpoint  
  - Sends user photo + selected outfit images to **Google Gemini Virtual Try-On API** or **OpenAI Sora 2**  
  - Returns AI-generated images to display

---

### ⚙️ Tech Stack
- **Frontend:** React + TailwindCSS (with sleek animations, gradients, hover effects)  
- **Backend:** Flask (AI API proxy)  
- **Libraries/APIs:** Axios, FullCalendar, Google Gemini / OpenAI Sora 2, Web Share API, HTML Canvas API, Google Calendar API (optional)  

---

### 🧩 Project Structure
Components:
- `Navbar.jsx` → logo + app name  
- `UserForm.jsx` → form + personalized greeting  
- `OutfitRecommendations.jsx` → product cards  
- `SuggestedLooks.jsx` → 3 complete looks + Try-On buttons  
- `VirtualTryOn.jsx` → AI-generated images side-by-side  
- `TrainingPlan.jsx` → dual-view (Quick & Detailed)  
- `CalendarView.jsx` → FullCalendar integration  
- `ShareCard.jsx` → generate shareable image  

Backend:
- `app.py` → Flask server with `/tryon` endpoint calling AI model

Other:
- `mockData.js` → Adidas-style outfits  
- Tailwind config → custom colors & gradients  
- Setup:  
  - Frontend: `npm install && npm start`  
  - Backend: `pip install -r requirements.txt && flask run`

---

### 🎯 Goal
Deliver a **fully interactive, professional, and stylish web app** that:
- Greets the user by name  
- Shows 3 complete Adidas-style suggested looks  
- Generates **AI try-on images for each look**  
- Provides a **dual-view training schedule** (Quick/Compact & Detailed)  
- Interactive calendar with “Mark Done” and reschedule  
- Allows sharing results as an image or via Web Share  
- Features a modern, classy, Adidas-inspired interface with animations, gradients, and logo
